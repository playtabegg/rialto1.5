Three steps01

1

Point Rialto at your game

Put the game in a folder of its own, anywhere on your PC, then hit Browse for your game folder at the top of the window. Everything below it starts looking in that folder from then on.

2

Fill in the name and the art

Title, developer, a background, a logo, an icon. Type the title and half the other boxes fill themselves in. Hover any field to be told exactly what it wants.

3

Preview, then build

Preview Disc Menu opens the real menu in a few seconds so you can look at it before committing. Then BUILD GAME INSTALLER. Your ISO lands in the output folder, ready for any disc writing tool.

The bar along the bottom A small disc fills up as you go, showing how much of your chosen media the game takes. It measures your folder before compression, so with Balanced or Smallest disc the finished ISO is often smaller than the number shown, and with Fastest install about the same. During a build the same line says what Rialto is doing, how far it has got and for how long.

From you

The gameA finished Windows build that runs from its own folder
BackgroundAn animated GIF or a still JPG, at 1280x720
Game logoTransparent PNG, around 400x150
Icons.ico files at 256x256. icoconvert.com turns a PNG into one.
Two files, one folder A release download gives you Rialto.exe and menu.exe. Keep them in the same folder. menu.exe is the disc menu Rialto puts on every disc it makes; without it beside Rialto, builds fall back to a plain text menu.

Your game folder03

There is no required layout. Rialto reads the folder as it finds it and works out which file is the game. Three folder names mean something extra if you use them:

MyGame\ game.exe or whatever your game is actually called Data\, Engine\, etc. everything your game needs, untouched bonus\ soundtrack, art, the design doc: a BONUS button mods\ a mod manager exe: a MODS button

Both of those can also be pointed at a folder anywhere else on your PC from Disc, Disc Extras, which has buttons that make them for you in the right place.

Disc

FieldWhat it is
Games on DiscLeave it alone for a normal single-game disc: Rialto finds the game by itself. Click Add Games, then double-click two or more games to tick them, and players get the Choose Your Game page: double features, demo collections, anthologies. For a demo disc, put each game in a folder of its own inside your game folder and click Find a game in each folder: every folder becomes a game, named after the folder, with an icon.ico, icon.png, cover.png or cover.jpg from that folder as its picture. Give each one a line under One line about it, set the order the Choose Your Game page shows with Move Up and Move Down, and tick A Start Menu shortcut for each game if players should be able to start a game without the menu. Once the games are installed, the main menu lists every game under Play Games, A to Z, and Play Games opens the Choose Your Game page, where players can sort the games and star favorites. A starred game moves to the top of both lists. To look at it before you build, click Preview Disc Menu, then PLAY GAMES.
Target MediaThe disc you plan to write. If the game will not fit, Rialto splits the installer and builds a numbered multi-disc set on its own.
Disc ExtrasBonus content, mods, an Add to Steam button, a compatibility mode, files for the player's PC, Mac and Linux builds. All optional. See below.
Files to Place on the PCIn Disc Extras, the Files to Place on the PC button at the bottom left (and in the Disc menu). For a game that needs files it would normally make on its first run, such as a mod's settings or a pre-made save: add each file or folder and pick where the installer copies it, in Documents, Saved Games, AppData (Roaming, Local or LocalLow) or the install folder, plus a sub-folder typed the way the game expects it, like MyStudio\MyGame. A file the player already has is never replaced unless you untick Keep existing, and the files stay after an uninstall unless you tick Remove on uninstall, so saves are safe both ways. Files go to the account of whoever installs the game. Keep the files in a folder inside your game folder: Rialto only places files from there. Outside the install folder it places data only, never a program, script or shortcut, and never into a folder Windows starts programs from. Windows only: Mac and Linux builds have no installer.

Disc extras05

Everything in this dialog is off or empty by default. Your disc builds fine without any of it.

Bonus content

Soundtracks, wallpapers, concept art, the design document, a thank-you letter. It becomes a BONUS button on the disc menu that opens the folder. Create Bonus Folder makes one inside your game folder and opens it in Explorer.

Mods

Drop a mod manager or loader .exe into a mods folder and tick the box. The folder rides along on the disc and a MODS button on the menu runs the tool, from the disc and after installing. Rialto finds the exe for you.

Compatibility mode

A second play button on the menu that starts the game with a launch argument already set, so a player on older hardware does not have to know the argument exists. Type exactly what you would type after the .exe, such as -opengl. Then say in one sentence what it does, in their words, and the menu shows that when they hover the button. Only worth ticking if your game already reads the argument.

Steam

After players install, the menu can offer one click to add the game to their Steam library as a non-Steam game. If Steam is open, the menu asks them to exit it completely and press the button again.

Mac and Linux

Only if you built them. Point at a plain build folder, the one you would have zipped up yourself, and Rialto packs it into an archive that carries the file permissions a disc cannot. The player copies it off the disc, opens it, and plays: no Terminal and nothing to type. Already made a .dmg, a .zip or an .AppImage? Point at the folder holding it and Rialto ships it exactly as it is.

Windows players get setup.exe and the menu, Mac players get a Mac folder, Linux players get a Linux folder. The disc's README.txt carries the real steps for all three side by side, naming the file to copy and what to do once it is open, so nobody has to read a second file to find out which buttons to press. Each folder still has its own START HERE.txt for anyone who copies the folder on its own, and only the platforms actually on the disc are named.

Compression

The Compression box on the Target Media row sets how hard the installer squeezes your game. Balanced suits most games. Smallest disc squeezes hardest: a smaller disc and a slower build. Fastest install stores the game as it is, so setup only copies it. That can mean more discs, and the size estimate becomes exact. Most modern games are already compressed inside, so storing them often costs little.

The Build Queue

Build Queue, beside Browse for your game folder (and in the Disc menu), builds several discs one after another. Add a saved profile and the game folder it builds, as many times as you like, tick the rows to build and press Build All. Each row builds exactly as BUILD GAME INSTALLER would, nothing stops to ask a question, and at the end one summary lists every disc and its size, or why a row failed. Stop After This One finishes the disc in progress and leaves the rest. Save a queue to build the same set again after a patch. Your own form comes back as it was when the queue ends.

While any build runs, the line under the log says what Rialto is doing and how far it is, with the time so far: copying your game and its extras, compressing the installer, signing, writing the disc image, checksumming it for a plant. The window keeps answering, so you can move it and scroll the log; the rest of the page waits until the build ends.

Pressing your disc

Tick Pressed beside Target Media when a plant will make your discs rather than you burning them. The disc is the same image either way. Rialto adds what the plant asks for: Chksum.md5, and a master sheet with each image's size in sectors, its checksum, its volume label and whether setup.exe is signed. For DVD DL it works out the layer break, and says so when your game would fit a single-layer DVD, which presses cheaper. Pressing works with CD and DVD, full size or 8 cm, and DVD DL, made with mkisofs. The sheet names a Mini as an 8 cm CD-ROM or an 8 cm DVD-5, which some plants call DVD-1. Before you order, ask the plant three things: do they press a data disc from an ISO image, will they press a data Blu-ray without copy protection, and for DVD DL do they want one image with the break on a sheet or one image per layer. This follows the plants' published specifications and has not been through a real pressing yet. Turn on Sign Final Build first: nobody can re-sign a disc once the plant has it.

When it goes wrong07

What you seeWhat to do
Preview says it cannot find menu.exe You have Rialto.exe but not menu.exe. Both come in the release zip; unzip the whole folder and keep them together.
Nothing happens on double-click (source checkout) Rialto.pyw runs windowless, so a startup error has nowhere to print. Run scripts\debug_rialto.bat instead: same thing, with a console, and it pauses on every error.
Windows says Python is installed but Rialto disagrees A clean Windows ships a placeholder at %LOCALAPPDATA%\Microsoft\WindowsApps\python.exe that only opens the Store. Install the real one from python.org with "Add python.exe to PATH" ticked.
The pre-build check says a tool is missing This copy of Rialto.exe is missing the tools it carries. Download Rialto again and keep the whole folder. Or install Inno Setup 6, or the Windows ADK with Deployment Tools ticked.
A ZIP instead of an ISO Every disc image tool Rialto tried failed. The log names each one and what went wrong. Check free disk space and that no scanner is holding the build folder, then build again.
The disc menu says the game executable was not found Click Play once more first: a freshly installed folder is sometimes still being scanned. If it persists, open Games on Disc in Rialto, tick your game's exe by hand and rebuild. That writes the exact path into the disc menu instead of leaving it to find one.
A disc in the set is bigger than the media Disc 1 always carries the menu, the setup stub and the extras, however big those are. Move to larger media or trim the bonus folder.

The fine print08

What lands in output

One .iso per disc, named after your game. Everything else Rialto used to build it is cleaned up. Write the ISO with any disc writing tool.

Every build starts clean: Rialto clears output\<your game> first, earlier disc images included, and the log says so. To keep an image, for example to compare two Compression choices, move it out of that folder before building again.

What the disc contains

setup.exe and its data slices, a menu\ folder holding the disc menu and its artwork, autorun.inf, the disc icon, a readme, and your bonus and mods folders if you used them.

Where it installs

C:\Games\<Your Game> by default, changeable by the player at install time. Uninstall is a normal Windows uninstall, from Settings or from the disc menu.

Languages

The installer offers 21 languages. The disc menu offers 34. It opens in the language the disc was built with, and the player can switch.

Profiles

File, Save Profile writes every setting to a .json in templates\. Rialto reloads the last one you used on the next start, so building the same game twice is two clicks.

Signing

Optional, and you bring your own account. Windows keeps a list of publishers it trusts; signing puts your studio on it, so the install prompt says who made the game instead of "Unknown Publisher". About $10 a month. Skip it and everything still builds. Configure Signing is in the bar along the bottom, and the signing guide covers the whole setup.

White label

Remove WTI Branding takes the We the Indies bird and wordmark off your disc menu, so the disc carries only your own. No charge, no strings, no attribution needed.

Controllers

The disc menu is fully navigable with a gamepad, because a disc very often ends up in a machine plugged into a television.

Windows 7 and 8

The disc menu needs Windows 8.1 or later. The installer still runs on Windows 7 SP1 and Windows 8, where the player opens setup.exe on the disc, and there its Start Menu and desktop shortcuts start the game itself instead of the menu: one shortcut for each game on a disc of several. The player loses the menu, not the game. This was checked under Windows' own Windows 7 compatibility mode, not on a Windows 7 PC.

A short screen

Rialto's window is 700 wide and as tall as your screen allows. The three steps card starts folded on every screen (Show opens it). When the page still does not fit, Rialto lays the same page out in fewer lines, up to three times: fields two to a row and less space between them. No text gets smaller and nothing scrolls. On a very short screen the log is cut first, and the log says so. Lowering Windows' display Scale makes room.

Check the disc before you send it anywhere Rialto is free software offered as-is, with no warranty. It keeps its settings and builds in its own folder, uses Windows' temp folder while it works, and never uploads your game. Keep your own backup, and test the ISO before it goes to a duplicator.
